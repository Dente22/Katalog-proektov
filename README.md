# Каталог проектов

Десктопное приложение (Electron): сетка карточек по папкам с описаниями из `card.md` / `card.dm`.

## Запуск

```bat
start.bat
```

или

```bash
npm install
npm start
```

## Возможности

- Сетка карточек по папкам **первого уровня**
- Описания из `card.md` / `card.dm`
- Логотипы (`logo` / `icon` / `favicon` на 1–2 уровнях)
- **Создать папку** внутри корня → пишется `card.md` и копируются все скилы из `.cursor/skills` каталога
- **Разделы (теги)** — несколько на проект, фильтр, можно добавить свой
- **Рейтинг 1–5**, фильтр по звёздам, сортировка 5→1 / 1→5
- Открыть в Cursor / VS Code / проводнике
- Скролл списка сохраняется при возврате из карточки

Метаданные (теги, рейтинг) хранятся в настройках приложения, не в папках проектов.

## Установка и обновление

1. Собери установщик: `build.bat` → `release\Katalog-proektov-Setup-*.exe`
2. Первый раз запусти Setup — установит «Каталог проектов» (данные в AppData не сотрутся при обновлении)
3. Когда что-то поменял в коде — снова `build.bat` (подними `version` в `package.json` при желании)
4. В приложении кнопка **Обновление** (или вопрос при старте) найдёт новый Setup в `release\` и поставит поверх без удаления

Папка обновлений по умолчанию: `D:\Project\просмотр\release` (можно выбрать другую).
