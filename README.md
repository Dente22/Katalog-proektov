# Каталог проектов

Десктопное приложение (Electron): сетка карточек по папкам с описаниями из `card.md` / `card.dm`.

## Запуск

```bat
start.bat
```

или

```bash
npm install
npm start
```

## Возможности

- Сетка карточек по папкам **первого уровня**
- Описания из `card.md` / `card.dm`
- Логотипы (`logo` / `icon` / `favicon` на 1–2 уровнях)
- **Создать папку** внутри корня → пишется `card.md` и копируются все скилы из `.cursor/skills` каталога
- **Разделы (теги)** — несколько на проект, фильтр, можно добавить свой
- **Рейтинг 1–5**, фильтр по звёздам, сортировка 5→1 / 1→5
- Открыть в Cursor / VS Code / проводнике
- Скролл списка сохраняется при возврате из карточки

Метаданные (теги, рейтинг) хранятся в настройках приложения, не в папках проектов.

## Скачать

Готовый установщик Windows: [Releases](https://github.com/Dente22/Katalog-proektov/releases) → `Katalog-proektov-Setup-*.exe` (актуальный: **v1.1.4**).

Запустите Setup — появятся ярлыки на рабочем столе и в меню «Пуск». Настройки в AppData при обновлении не стираются.

## Собрать установщик самому

Нужен [Node.js LTS](https://nodejs.org/). Затем:

```bat
build.bat
```

Готовый файл: `release\Katalog-proektov-Setup-1.1.4.exe`.

- Мастер установки (можно выбрать папку)
- Ярлыки на рабочем столе и в меню «Пуск»
- Обновление поверх без удаления настроек в AppData
- Удаление — через «Приложения» Windows

После сборки запустите Setup. Когда появится новая версия: снова `build.bat`, в приложении кнопка **Обновление**.

Папку с новыми Setup.exe можно указать в приложении (по умолчанию ищется `release\` рядом с проектом).
